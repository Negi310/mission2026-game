# 6種類のスペシャルアイテム

2026-10-07更新。ユーザー指定の6種類を実装。ラウンド中に能力値を上げる既存のパワーアップとは別に管理します。数値は試作用です。

## 発動と保持

メガビーム・ギガント爆弾は取得後、既存の砲撃入力（Space/J/K、左右パッド）で使用します。ミサイル・マグネット・ブルドーザー・ハイスピードは取得時に自動発動します。追加ボタン・手動切り替えはありません。

レーザー・巨大爆弾の保持枠は1つ。枠が埋まっている場合は次の武器を取得せず、アイコンを残します。武器が発動中でも次の武器を保持できますが、使用は効果が終わってからです。ミサイルは保持枠・発動中の武器とは独立して飛び、どちらの武器とも併用できます。ビーム中は通常砲撃と車体の旋回・前進を止め、砲塔の操舵を受け付けつつミサイルの自動攻撃も続きます。

自動発動の4種類はそれぞれのタイマーを持ち、併用できます。同じ種類を再取得すると残り時間を初期値に更新します。ミサイルは再取得時も5発を維持し、レーザー終了や爆弾起爆で消えません。ラウンド終了で飛行中のミサイルを破棄します。ブルドーザーと高速の速度倍率は掛け合わせます。ビームは高速より優先して前進を止めます。HUDは保持武器・次の砲撃で使用する案内・全効果の残り秒数を表示します。

能力強化アイコンは丸形、スペシャルは白枠の六角形。レーザー・5本のミサイル・磁石・ブレード・爆弾・速度線の2Dシルエットをコードで描画し、マテリアルとテクスチャを種類ごとに共有します。

追尾対象は走行中の車、ドラム缶・燃料タンクなどの爆発物、歩行中の通行人です。選択時に距離90以内、砲口の水平方向から左右50度以内、現在のカメラの画面内にあることを条件にし、カメラから対象へ建物などの遮蔽物があれば除外します。その候補内で車と爆発物を優先し、通行人だけが残れば通行人へ向かいます。選択済みの対象が画面外へ動いても追尾は続け、破壊・退避した場合に現在の前方視界から選び直します。通行人は爆風で転がった後に歩道へ戻ります。対象がいなければ前方の地面へ向かいます。実際の移動経路を球の掃引判定で調べるため、途中の建物に当たった場合はそこで炸裂します。

いつもの街は33棟、大きな街は132棟に1個ずつ割り当てます。6種類を均等に近い個数で用意してシードでシャッフルし、建物の形・階数とは独立に割り当てます。外壁はアイテムと同じ色（水色＝ビーム、オレンジ＝ミサイル、ピンク＝磁石、黄色＝ブルドーザー、赤＝爆弾、青＝高速）です。全構造部材が分離した時点で、建物の真下の中心に円形エリアと大きなアイコンを表示します。屋根だけの破壊や一部の倒壊では出しません。破片を削除しても分離済みの部材数を保持します。

円の半径は建物幅の65%（最低7）、光の高さは3.8です。外縁の光が上へ流れ、円は地面の高さに沿います。戦車の中心が円の中へ入ると取得し、円とアイコンが消えます。マグネットで吸引中も円の中心を動かさず、アイテムが水平面で円の外へ出た時点で円を消します。その後もアイテムは回収可能です。保持枠が満杯なら取得を保留し、引き出したアイテムの吸引が止まった場合は地面・残存建物と物理衝突します。飛散破片と戦車の車体からは押されず、寿命では消えません。道路上の能力強化はいつもの街76個、大きな街292個です。レーザーの射程はいつもの街400、大きな街800で、どちらも対角の端まで届きます。

## 破壊・終了・復帰

アイテムによる破壊も通常砲撃と同じ部材の分離・支持喪失・重心による倒壊を使います。Rigidbodyによる飛散、破片の上限2,000・寿命3.6〜4.8秒、同じ部材の重複加点防止を共有します。大爆発では爆風の物理的な力が届く範囲も拡大します。

ブルドーザー・高速の無敵は衝突爆発と時間ペナルティを防ぎます。街の端を越えた場合は開始地点へ戻します。通常の爆発時は保持武器を維持し、既に発射したミサイル・爆弾は続行します。ビーム・磁石・巨大化・高速は解除します。停止中はすべてのタイマーが止まり、結果画面では武器・効果・巨大化を終了します。再挑戦で街とアイテムを作り直します。

## 戦車の操舵

砲塔はハンドル値に合わせて左右最大22度へ速度210度/秒で回転します。車体は0.08秒前のハンドル値を受け、応答12で操舵を滑らかに変えて旋回します。従来の遅延0.2秒・応答5から反応を速め、先行角も38度から22度へ抑えています。砲塔と車体表示の回転は物理更新間を描画フレームごとに補間します。カメラは砲塔の水平な向きへ緩やかに追従し、最大回転速度135度/秒・角加速度240度/秒²で切り返しをつなぎます。後方9.0・高さ3.0から水平を保ち、坂道の上下や巨大化時の距離変更は滑らかに追従します。画面揺れや遮蔽物による急なズームは使いません。照準と実際の砲撃方向も砲塔へ追従します。車の操舵角・ホイールベースによる旋回式を置き換えています。加速、横方向の慣性とグリップ、坂道追従、破片による勝手な旋回の防止は維持します。砲身の上向き4度は砲塔の回転後も適用し、実際の砲弾方向と照準を一致させます。

調整は `Assets/TankTown/Resources/TankTownSettings.asset`。円の最低半径・建物幅に対する比率・外縁の光の高さは `specialAreaMinRadius`、`specialAreaWidthRatio`、`specialAreaLightHeight`。取得条件は全壊に固定しています。現在の取得方式と検証は[円形報酬エリア](reward-area-validation.md)、追尾・交通量・拡大レーザーは [homing-crowds-laser-validation.md](homing-crowds-laser-validation.md)、以前の落下報酬は [city-presentation-validation.md](city-presentation-validation.md) を参照してください。

マグネット・巨大爆弾・ミサイルの強化仕様と検証は[記録](extreme-specials-validation.md)を参照してください。

取得時のミサイル自動発射・併用と2つのステージの検証は[記録](auto-missiles-stages-validation.md)を参照してください。
