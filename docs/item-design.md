# 6種類のスペシャルアイテム

2026-10-02。ユーザー指定の6種類を実装。ラウンド中に能力値を上げる既存のパワーアップとは別に管理します。数値は試作用です。

## 発動と保持

メガビーム・ミサイル・ギガント爆弾は取得後、既存の砲撃入力（Space/J/K、左右パッド）で使用します。マグネット・ブルドーザー・ハイスピードは取得時に自動発動します。追加ボタン・手動切り替えはありません。

武器の保持枠は1つ。枠が埋まっている場合は次の武器を取得せず、アイコンを残します。武器が発動中でも次の武器を保持できますが、使用は効果が終わってからです。ミサイル・爆弾の発動中は通常の砲撃もできます。ビーム中は通常砲撃と車体の旋回・前進を止め、砲塔の操舵は受け付けます。

自動発動の3種類はそれぞれのタイマーを持ち、併用できます。同じ種類を再取得すると残り時間を初期値に更新します。ブルドーザーと高速の速度倍率は掛け合わせます。ビームは高速より優先して前進を止めます。HUDは保持武器・次の砲撃で使用する案内・全効果の残り秒数を表示します。

能力強化アイコンは丸形、スペシャルは白枠の六角形。レーザー・5本のミサイル・磁石・ブレード・爆弾・速度線の2Dシルエットをコードで描画し、マテリアルとテクスチャを種類ごとに共有します。街には24個を置き、最初の直線の左右に各1種類を配置します。

## 破壊・終了・復帰

アイテムによる破壊も通常砲撃と同じ部材の分離・支持喪失・重心による倒壊を使います。Rigidbodyによる飛散、破片の上限280・寿命9秒、同じ部材の重複加点防止を共有します。大爆発では爆風の物理的な力が届く範囲も拡大します。

ブルドーザー・高速の無敵は衝突爆発と時間ペナルティを防ぎます。街の端を越えた場合は開始地点へ戻します。通常の爆発時は保持武器を維持し、既に発射したミサイル・爆弾は続行します。ビーム・磁石・巨大化・高速は解除します。停止中はすべてのタイマーが止まり、結果画面では武器・効果・巨大化を終了します。再挑戦で街とアイテムを作り直します。

## 戦車の操舵

砲塔はハンドル値に合わせて左右最大22度へ速度210度/秒で回転します。車体は0.08秒前のハンドル値を受け、応答12で操舵を滑らかに変えて旋回します。従来の遅延0.2秒・応答5から反応を速め、先行角も38度から22度へ抑えています。カメラは車体後方から砲塔の向きへ追従し、照準と実際の砲撃方向も砲塔へ追従します。車の操舵角・ホイールベースによる旋回式を置き換えています。加速、横方向の慣性とグリップ、坂道追従、破片による勝手な旋回の防止は維持します。砲身の上向き4度は砲塔の回転後も適用し、実際の砲弾方向と照準を一致させます。
