# 6種類のスペシャルアイテム

2026-10-05更新。ユーザー指定の6種類を実装。ラウンド中に能力値を上げる既存のパワーアップとは別に管理します。数値は試作用です。

## 発動と保持

メガビーム・ミサイル・ギガント爆弾は取得後、既存の砲撃入力（Space/J/K、左右パッド）で使用します。マグネット・ブルドーザー・ハイスピードは取得時に自動発動します。追加ボタン・手動切り替えはありません。

武器の保持枠は1つ。枠が埋まっている場合は次の武器を取得せず、アイコンを残します。武器が発動中でも次の武器を保持できますが、使用は効果が終わってからです。ミサイル・爆弾の発動中は通常の砲撃もできます。ビーム中は通常砲撃と車体の旋回・前進を止め、砲塔の操舵は受け付けます。

自動発動の3種類はそれぞれのタイマーを持ち、併用できます。同じ種類を再取得すると残り時間を初期値に更新します。ブルドーザーと高速の速度倍率は掛け合わせます。ビームは高速より優先して前進を止めます。HUDは保持武器・次の砲撃で使用する案内・全効果の残り秒数を表示します。

能力強化アイコンは丸形、スペシャルは白枠の六角形。レーザー・5本のミサイル・磁石・ブレード・爆弾・速度線の2Dシルエットをコードで描画し、マテリアルとテクスチャを種類ごとに共有します。

追尾対象は走行中の車と歩行中の通行人です。選択時に距離90以内、砲口の水平方向から左右50度以内、現在のカメラの画面内にあることを条件にし、カメラから対象へ建物などの遮蔽物があれば除外します。その候補内で車を優先し、通行人だけが残れば通行人へ向かいます。選択済みの対象が画面外へ動いても追尾は続け、破壊・退避した場合に現在の前方視界から選び直します。通行人は爆風で転がった後に歩道へ戻ります。対象がいなければ前方の地面へ向かいます。実際の移動経路を球の掃引判定で調べるため、途中の建物に当たった場合はそこで炸裂します。

33棟の建物それぞれの最上階の床に1個を配置します。6種類を均等に近い個数で用意してシードでシャッフルし、建物の形・階数とは独立に割り当てます。建物の外壁はアイテムと同じ色（水色＝ビーム、オレンジ＝ミサイル、ピンク＝磁石、黄色＝ブルドーザー、赤＝爆弾、青＝高速）です。支える床の分離、または建物の破壊率60%以上でRigidbodyを動的にして落下させます。途中に残る床があればその床で止まり、床を追加破壊するとさらに落下します。取得はその建物の部材の60%以上が分離した後に限ります。破片の削除後も分離済みの部材数を保持します。

報酬は地面・残存建物と物理衝突し、飛散破片と戦車の車体からは押されません。戦車との取得用トリガーは有効です。寿命による消去はなく、保持枠が満杯なら地上に残ります。落下中の光の軌跡、回収可能時の光、取得時のHUD通知を表示します。能力強化76個は引き続き道路上に配置します。

## 破壊・終了・復帰

アイテムによる破壊も通常砲撃と同じ部材の分離・支持喪失・重心による倒壊を使います。Rigidbodyによる飛散、破片の上限2,000・寿命3.6〜4.8秒、同じ部材の重複加点防止を共有します。大爆発では爆風の物理的な力が届く範囲も拡大します。

ブルドーザー・高速の無敵は衝突爆発と時間ペナルティを防ぎます。街の端を越えた場合は開始地点へ戻します。通常の爆発時は保持武器を維持し、既に発射したミサイル・爆弾は続行します。ビーム・磁石・巨大化・高速は解除します。停止中はすべてのタイマーが止まり、結果画面では武器・効果・巨大化を終了します。再挑戦で街とアイテムを作り直します。

## 戦車の操舵

砲塔はハンドル値に合わせて左右最大22度へ速度210度/秒で回転します。車体は0.08秒前のハンドル値を受け、応答12で操舵を滑らかに変えて旋回します。従来の遅延0.2秒・応答5から反応を速め、先行角も38度から22度へ抑えています。砲塔と車体表示の回転は物理更新間を描画フレームごとに補間します。カメラは砲塔の水平な向きへ緩やかに追従し、最大回転速度135度/秒・角加速度240度/秒²で切り返しをつなぎます。後方9.0・高さ3.0から水平を保ち、坂道の上下や巨大化時の距離変更は滑らかに追従します。画面揺れや遮蔽物による急なズームは使いません。照準と実際の砲撃方向も砲塔へ追従します。車の操舵角・ホイールベースによる旋回式を置き換えています。加速、横方向の慣性とグリップ、坂道追従、破片による勝手な旋回の防止は維持します。砲身の上向き4度は砲塔の回転後も適用し、実際の砲弾方向と照準を一致させます。

調整は `Assets/TankTown/Resources/TankTownSettings.asset`。取得に必要な倒壊率は `buildingRewardThreshold`。追尾・交通量・拡大レーザーは [homing-crowds-laser-validation.md](homing-crowds-laser-validation.md)、落下報酬は [city-presentation-validation.md](city-presentation-validation.md)、以前の6種類の効果は [items-validation.md](items-validation.md) を参照してください。
