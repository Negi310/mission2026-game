# 操作感の調整

タイトルまたはプレイ中に **F7** を押して調整画面を開きます。画面を閉じるにはF7または「閉じる」を使います。画面はスクロールできます。開いている間もゲームと制限時間は進みます。

- 戦車：移動速度、加速、旋回速度、旋回の反応、横滑りの抑え、車体の旋回遅れ、砲塔の最大旋回角・追従速度、射撃間隔。
- micro:bit：ハンドルの中立、最大旋回までの入力、中立付近の遊び、左右反転、砲撃の閾値・再受付値・打撃の連続受付間隔。

スライダーを動かして「適用」を押すと、次の操作から反映されます。「適用して保存」なら同じPC・Windowsユーザーの次回起動にも引き継ぎます。「初期値に戻す」は初期値をその場で適用します。初期値を次回にも引き継ぐには続けて「適用して保存」を押してください。

中立合わせを使う場合は、micro:bitが接続されている状態でハンドルを真っ直ぐにし、「現在のハンドル位置を中立にする」→「適用」を押します。ハンドルの設定を適用すると入力がいったんリセットされ、次のデータから再開します。設定した感度はキーボードの左右操作には影響しません。

F8の接続診断とF7の調整画面は同時には開きません。F8で砲撃の閾値を保存したとき、F7で保存済みの値にも反映されます。F7で保存したコントローラー設定は同じPCユーザーの設定として読み込むため、同梱JSONの同項目より優先されます。
