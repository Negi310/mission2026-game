# 揺れ幅を抑えた速いレーザー振動（2026-10-25）

標準振幅を0.28→0.14mへ半減。左右の主成分を12→18Hz、補助成分を15→23Hz、上下を14→21Hzへ上げました。前回より小さな範囲で、約1.5倍速く震える調整です。[前回の調整](beam-recoil-fast-validation.md)。

低フレームレートでは、主成分がサンプリングで消えないよう1フレームの進みを0.45周期以下に制限します。位相を連続して積み上げるため、フレームレートが変わっても波形が突然切り替わりません。60fpsでは18Hz、30fpsでは主成分13.5Hzになります。補助成分は主成分に対する比率を保ちます。

カメラの回転・画角を変えない構造、0.18秒の立ち上がりと0.24秒の減衰、停止・中断・Snap、追従と遮蔽物判定への反動の混入を防ぐ処理は維持しています。
