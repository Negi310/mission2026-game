# タイトル・開始・結果の画面フロー

2026-10-05。[Issue #5](https://github.com/Negi310/mission2026-game/issues/5)。

街を見てすぐ遊び、結果からもすぐ次のラウンドへ進める構成です。`TankTownRoundFlow`が待機カメラ・短い暗転・開始カウントダウンを管理し、タイトルと結果のUIは独立したクラスです。プレイ中のカメラの追従・水平維持・遮蔽物処理は従来の`TankCamera`を使います。

タイトルの背景は実際に生成した街です。一番高い屋根と屋上設備の上端より9上から毎秒3.5度で巡回します。回転半径はフィールド半幅の1.22倍、注視点は屋根の高さの35%で、街を横から少し見下ろす構図です。ズーム・上下の揺れ・ロール・突然の方向変更は加えません。建物を見分けられるようにタイトル中だけ影の描画距離を430へ伸ばし、霧の開始・終了を430・700へ遠ざけます。プレイへ移ると影95・霧160〜410へ戻します。タイトルと遊び方の待機中は`Time.timeScale = 0`で、街の物理演算と60秒の制限時間は止めます。カメラとUIは実時間で更新します。

| 操作 | 挙動 |
| --- | --- |
| タイトルでH、あそびかたボタン | 操作と6種類のスペシャルの説明を開く |
| 遊び方でEsc、もどるボタン | タイトルへ戻る |
| タイトル・遊び方でSpace/J/K/Enter/パッド | 開始演出へ。開始入力では砲撃しない |
| リザルトでSpace/J/K/Enter/パッド、もういちどボタン | 数字の演出中でも即座に再挑戦へ |
| プレイ中にSpace/J/K/パッド | 通常砲撃・武器アイテムの発動 |
| 一時停止中にSpace/J/K/Enter | 続ける |

開始は0.10秒で画面を暗くし、完全に覆ったフレームで屋根の高さの巡回から戦車視点へ切り替え、0.12秒で戻します。その後3・2・1を各0.22秒で大きく表示し、GO!で操作・タイマーを開始します。GO!は0.40秒だけ残ります。Starting状態では連打を受けても砲撃・二重開始をしません。重いフレームでも数字を丸ごと飛ばさないよう、開始演出の1フレームの進行時間を0.08秒までに制限します。

再挑戦はRestarting状態で0.10秒の暗転を行い、新しい街を生成します。新しいシーンは覆った画面から0.12秒で復帰し、同じ3・2・1を表示します。Starting/Restarting中の追加の開始入力は無視します。生成中の画面は覆ったままで、生成所要時間は環境に依存します。タイトルへ戻る操作では待機カメラと停止状態へ戻します。

スコアは`round(clamp(破壊度, 0, 100) × 1000)`です。部材数の違う街でも同じ破壊度なら同じ点数になり、100%で100,000点です。別途、壊した部材数、燃料・車・破片を含む連鎖爆破の累計、最長の連鎖段数、リスポーン回数を表示します。既存の連鎖・破壊判定は変更していません。

リザルトは0.26秒でカードを出し、0.95秒でスコアと破壊度を数え上げます。4種類の記録を順に表示し、紙吹雪を有限時間だけ流します。画面・カメラの揺れは加えません。ランクは35%未満C、35%以上B、60%以上A、85%以上Sで称号も表示します。ベストスコアは`TankTown.BestScore.v1`として端末のPlayerPrefsへ保存し、更新時はNEW BEST!を表示します。

タイトル・遊び方・リザルトは1440×900のレイアウト全体が画面に収まるように拡縮します。HUDと開始・復帰の暗転は別に管理し、復帰の暗転がリザルトに残らない既存仕様も維持します。

既存のゲームプレイ検証は明示的に開始演出を省略し、専用の画面フローテストと`--tank-town-round-flow-smoke`では省略せず検証します。テストと診断はベストスコアを保存せず、プレイヤーの記録を変更しません。
