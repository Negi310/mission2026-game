# mainへの統合

2026-10-12。初回のUnityプロトタイプから、お菓子版の外壁支持修正（`fcedc59`）までの変更をまとめてmainへ統合します。通常・大型・お菓子ステージ、1分のゲームループ、部分破壊と倒壊、強化4種類・スペシャル6種類、車と連鎖爆発、タイトル・リザルト・ローカルランキング・ミニマップ・取得演出とHUDを含みます。

ゲームのソース、シーン、設定、テクスチャ、音声は直前に検証した内容をそのまま使います。追加の統合作業では、過去のスクリーンショット50件をLFSポインターから同じSHA-256の実体画像へ揃え、小さなゲーム用画像・音声を通常のGitバイナリとして扱う例外を追加しました。生成済みのステージ構想画像2件とそのプロンプトも保存します。

## 検証

- 直前のPlayMode検証は15/15成功。通常3種・お菓子6種の壁と梁の支持、累積ダメージ、装飾・テクスチャを確認しています。
- Windows x64 Development Buildが成功し、実プレイヤーで20画面を確認済みです。実砲撃で121部材中9部材が分離し、外壁43枚と上階の壁が残りました。
- 修正前後の画面をChromeで確認済みです。詳細は[外壁支持修正の検証](candy-wall-support-validation.md)を参照してください。
- 統合時は、Assets/TankTown内240ファイルのGit正規化後の内容が作業用コピーと一致すること、既存50画像のSHA-256がLFSの記録と一致することを確認しました。検証用コピーとの差は、改行とUnityが共有マテリアルへ補完したシェーダーの既定値だけです。今回、ゲームの挙動を変える修正は追加していません。

作業ディレクトリに残っていたUnityの自動更新設定は、ローカルの`codex/issue-5-pre-main-backup-20261012`へ保護し、手元の変更として保持します。Library・ログ・Windowsの配布ビルドはGit管理の対象外です。
