# 1分間の自動生成の街

2026-10-05。関連: [Issue #5](https://github.com/Negi310/mission2026-game/issues/5)。

新しいラウンド・タイトルへの帰還でシーンを作り直し、新しいシードで街を生成します。`TownLayout`は生成結果を持ち、`TankTownWorld`が建物・公園・アイテムを、`TownTerrain`がその地形を作ります。生成中に共有設定やUnityの演出用乱数を書き換えません。破壊度の分母は、そのラウンドで生成した部材数です。

道路は幅16・街区間隔40のつながった格子です。268×268のフィールド内に33棟・公園3か所・車72台・通行人72人を保ちます。建物の3種類の形、階数、色、公園の位置、敷地内の位置、パワーアップの位置と種類をランダムに選びます。入口の角には必ず建物を置き、入口の直線には4種類のパワーアップを置きます。各建物が平坦な敷地に収まる範囲で位置をずらし、幅の大きい建物は中心に配置します。道路そのものの接続パターンや外周は固定です。

建物の形と報酬を別の乱数系列で選びます。6種類の報酬を均等に近い個数で用意し、並びをシャッフルして全種類を確保します。外壁の色は`ItemIcons.Color`から取得し、同じ建物の実際の報酬を`BlockBuilding.RewardKind`として渡します。見た目と報酬を別々に推測する処理はありません。2026-10-07から報酬は屋上に表示せず、全壊後に建物の真下の中心へ円形エリアを出す方式へ変更しています。円に入ると取得し、マグネットでアイテムを円の外へ出した場合も円が消えます。[現在の取得方式](reward-area-validation.md)。

| 建物の色 | スペシャル |
| --- | --- |
| 水色 | メガビーム |
| オレンジ | 追尾ミサイル |
| ピンク | マグネット |
| 黄色 | ブルドーザー |
| 赤 | ギガント爆弾 |
| 青 | ハイスピード |

地形はシードから丘の波の位置を選び、交差点ごとの高さを求めます。標準の高さは0〜9.8以内です。交差点は平坦、道路間は滑らかな坂、敷地は四隅の高さの平均を使った平坦な面です。描画とMeshColliderは同じ高さ関数を使います。小物・車・人・報酬の着地・海岸もその地形を使います。

標準は`randomizeCitySeed = true`です。同じ街を再現する場合はfalseにして`citySeed`を指定します。プレイヤーの起動引数`--tank-town-seed=2026`でも固定できます。ログの`TOWN GENERATED: seed=...`で実際の値を記録します。テストはシード2026を明示し、さらに100通りのシードの配置・全種類・平坦な足元・道路の連続性を確認します。

制限時間は60秒です。タイトルの待機・一時停止は時間を消費せず、通常のリスポーンは3秒のペナルティと復帰待ち時間を消費します。通常砲撃や部材の耐久力は今回の時間変更に合わせた自動補正をしていません。

ミサイルは選択時に前方左右50度、距離90以内、画面内、遮蔽物なしの候補へ限定します。選択後は追尾を維持し、対象が使えなくなったときに現在の視界から選び直します。巨大爆弾は前方速度18から38、導火時間3秒から1.5秒へ変更し、物理的な接触破壊と半径30の爆発は継続します。
