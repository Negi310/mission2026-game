# 引いた視点で分かるレーザー反動（2026-10-25）

引いたレーザー専用視点で反動が見えにくかったため、標準振幅を0.055→0.28m（約5.1倍）へ変更。左右の波形を9/13→6/9Hz、上下を11→7Hzにし、細かい振動から動きが読める反動へ調整しました。Inspectorの範囲は0〜0.4m、0で無効です。

0.18秒の立ち上がりと0.24秒の減衰、回転・画角・画面に対する前後移動を加えない構造、追従と遮蔽物の判定から反動を除く処理、一時停止とSnapでの扱いは維持しています。[最初の反動の記録](beam-recoil-validation.md)。

既存のカメラテストは、意図した振動と障害物による基準位置の移動を分けて確認するよう調整しました。Windows診断では反動終了まで138フレームを観測し、固定した建物位置と戦車位置の投影が反動だけで何ピクセル変わるかを、1920×1080換算で計測します。比較は同じカメラから参照点を反動分だけ動かして行い、カメラ自体は計測のために動かしません。

## 検証

Unity 6000.3.19f1のPlayModeでカメラの12項目を確認。初回11件成功、1件は減衰中のフレーム差0.1903mが新しい振幅用に設定した試験上限0.185mを超えて失敗しました。立ち上がりと減衰を含む連続性の上限を0.21mに調整し、その1件を再実行して成功。製品側の振幅や波形は再実行前後で変更していません。回転・画角・追従への蓄積・一時停止・中断・再挑戦を確認しました。

Windows Development Build成功。通常街33棟・大型街132棟の実行はいずれも終了コード0。反動の実測最大幅は0.26389m、60fps固定刻みでフレーム間変化の最大は0.17747m。参照点の画面上の変化は建物位置5.52px、戦車位置15.75pxで、振動の存在だけでなく引いた視点で見える幅も確認しました。これは診断配置の投影値で、個人の体感評価ではありません。

レーザーの実際の命中は通常163・大型327。専用視点との移行を含むカメラ全体の最大フレーム移動は0.440m、角度変化は0.388度。画角72度を維持し、終了後の反動はゼロです。移行中・破壊中・復帰後の実画面も確認しました。

通常の`Builds/TankTown/TankTown.exe`と`Builds/TankTown-VisibleBeamRecoil/TankTown.exe`を更新。RuntimeアセンブリのSHA-256は両方とも`6F86DEE51D5B87DFE39FFE17847BB76658F47DBF3B73F703879FF618D19FDEC9`です。先のリザルト刷新・パフォーマンス最適化も含みます。

検証コピーとC# 109ファイルが改行正規化後に一致。利用者の描画設定・撮影コード9ファイルは作業前のハッシュと一致し、既存の削除3ファイルも復元していません。既存のAGENTSや開発手順の更新は不要です。
