# 速度16・加速度10の検証

実施日: 2026-10-02。Issue #5 に続く速度調整。

基本巡航速度を11から16へ約45%上げ、加速度も6から10へ変更しました。強化なしの発進では約1.6秒で巡航速度に達します。スピード強化1レベルで17.28、8レベルで26.24になります。操舵・地面追従・破片の押し返し・砲身の仰角は維持しています。

## テストの変更

発進から1秒の速度を9〜11で確認します。発進直後に最高速度へ跳ねないこと、旋回の横方向の慣性、操舵を戻した後の滑らかな直進復帰は引き続き検証します。

操舵を戻した後の直進は水平の向きで検証します。速度を上げた最初の実行では道路脇へ近づき、地面に沿った傾きを含む3D回転角の差が0.52度になりました。地面に沿った姿勢の変化を旋回として数えないよう、水平角の差に対して従来と同じ0.4度の上限を適用しています。

斜面のテストでは、必要な経路を通過して巡航速度を回復したら測定を終了します。以前の固定時間の走行では速度を上げると斜面を越えて次の建物まで到達してしまうため、走行距離と速度による終了条件を加えました。停止・勝手な旋回・地面による爆発がないことの検証と、経路ごとの時間上限は維持しています。
