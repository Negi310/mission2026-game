# レーザー中の小さなカメラ反動（2026-10-25）

レーザー発射中、画面の左右・上下へ最大約5.5cmの位置変化を加えます。横方向を中心とした9・11・13Hzの連続した波形で、フレームごとのランダムな跳ねを避けています。立ち上がり0.18秒、終了・中断後の減衰0.24秒。既存のレーザー専用視点の移行に重ねています。

カメラの回転・ロール・画角には揺れを加えず、画面に対する前後方向にも動かしません。追従の高さ計算から前フレームの反動を除き、基準位置へ蓄積しないようにしました。遮蔽物を透かす判定も基準位置で行い、振動だけで部材の表示状態が切り替わるのを避けます。地面への最低距離は維持します。

一時停止中は位相と位置を固定。Snap・コンポーネント無効化で反動を除去し、再開時は小さく立ち上がります。通常砲撃・爆発・他のスペシャルアイテムは反動を開始しません。`TankTownSettings.asset`の`megaBeamCameraShake`（標準0.055、上限0.08）を0にすると無効です。通常時に新しいオブジェクトや作業用配列を生成しません。

## PlayMode

Unity 6000.3.19f1の検証コピーで、カメラと照準の20項目を確認。最初は19件成功し、比較用カメラへ一時停止フラグを渡し忘れた新規テスト1件が失敗しました。比較側も同じ条件で停止するよう修正し、反動の2件と中断・再挑戦の既存1件を再実行、3件全て成功しています。製品コードは再実行前後で変更していません。

実測した反動の最大幅は0.05249m。反動のない比較カメラに対し、回転・画角が同一、位置差が反動幅内、画面に対する前後移動なし、終了後の位置差なしを確認しました。停止・再開、中断、Snap、無効化・再有効化、リスポーンと再挑戦でも残留しません。

記録：`Logs/beam-recoil-tests.xml`、`Logs/beam-recoil-final-tests.xml`と対応するログ。これは振幅や連続性の検証であり、個人の酔いにくさを測った試験ではありません。

両ステージとも反動の最大幅0.05427m、60fps固定刻みで反動のフレーム間変化は最大0.05220m。画角72度を維持し、終了後の反動はゼロ。専用視点への移行を含むカメラ全体の最大フレーム移動は0.371m、角度変化は0.388度です。レーザーの命中数は通常163・大型327、ブルドーザー90%と高速併用時1.98倍も維持しています。
