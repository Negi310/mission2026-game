# チェインの段数と誘爆回数

2026-10-05。`CHAIN`は連鎖の深さ、誘爆回数は爆発の累計です。時間内に連続射撃した回数や、壊したオブジェクト数とは別です。

砲弾の着弾は0段目として扱います。点火された車Aが爆発すると1段、その爆風で車Bが点火して爆発すると2段、車Bから車Cへ伝われば3段です。Aの爆風で車B・C・Dが並行して爆発した場合、深さは2段、誘爆の累計はAを含め4回です。

| 値 | 意味 |
| --- | --- |
| HUDの大きい数字 | 現在表示している連鎖の最大段数 |
| HUDの「誘爆合計」 | ラウンド中の爆発物と高速破片による爆発の累計 |
| 結果の最高連鎖 | ラウンド中に到達した最も深い段数 |
| 最終スコア | 街の部材の破壊済み割合。チェイン専用の得点倍率は現在なし |

車・ドラム缶は砲撃、体当たり、高速の物体の衝突でも点火し、0.18秒の導火時間で順番に爆発します。各爆発物は1回だけ爆発します。燃料タンクは表面から3以内で起きた爆発によって点火し、体当たりだけでは点火しません。燃料の爆風半径24・基準衝撃力の3倍は維持しています。車の爆風は半径10・1.6倍です。

飛び散る破片は生成元の段数を引き継ぎます。未破壊の部材へ正面方向の相対速度12以上で当たると、その接触位置から次の段の局所爆発を起こします。爆発で部材に効果があった場合にだけ、誘爆回数へ加算します。破片1個につき成功は1回、破片の爆発は4段まで。全体で0.12秒に3回までに制限します。ゆっくりした接触・横滑り・地面・戦車への接触では破片の誘爆は起きません。

車やドラム缶の連鎖には、破片と共通の4段上限を設けていません。爆発できる未消費の物体がなくなると連鎖が止まります。

表示中の数字は、並行した浅い枝が後から届いても小さく戻しません。新しい深さへ数字が増えるとポップ・加算・光の演出を出し、最高段数を更新すると「最高連鎖更新！」を表示します。最後の通知から2秒で表示を消し、次の連鎖ではその連鎖の段数から再開します。この2秒は表示の時間で、ゲームの連鎖成立条件ではありません。一時停止では演出時間も止まり、結果画面では表示を消します。
